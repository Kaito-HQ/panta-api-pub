---
title: Update account
description: Update the display name on the authenticated account.
api: PATCH /account/
---

<ParamField body="name" type="string" required>
  Non-empty display name (max 255).
</ParamField>

Response schema matches [Get account](/api-reference/account/get).

<RequestExample>
```bash cURL
curl -X PATCH https://api.panta.market/api/v1/account/ \
  -H "X-Api-Key: pk_test_…" \
  -H "Content-Type: application/json" \
  -d '{"name":"Acme Labs"}'
```
</RequestExample>
