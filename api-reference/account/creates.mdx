---
title: List creates
description: Create-flow rows for the authenticated account (includes eventPda / market ids).
api: GET /account/creates/
authMethod: "key"
---

Accepts `X-Api-Key` or `Authorization: Bearer <access>`.

Prefer [`GET /markets/?createdBy=me`](/api-reference/markets/list) for catalog DTOs of markets you created. This endpoint returns create-session metrics (`pending`, `registered`, …).

<ParamField query="limit" type="integer" default="50">
  Max rows (capped at `200`).
</ParamField>
<ParamField query="status" type="string">
  Optional create status filter (`pending`, `registered`, …).
</ParamField>

<ResponseField name="summary" type="object">
  Create totals (`total`, `byStatus`).
</ResponseField>
<ResponseField name="items" type="array">
  Create rows: `createId`, `wallet`, `eventPda`, `signature`, `status`, `paymentUsdc`, `createdAt`, `updatedAt`.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://live-api.panta.market/api/v1/account/creates/?limit=50&status=registered" \
  -H "X-Api-Key: pk_test_…"
```
</RequestExample>
